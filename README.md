# AR USDZ Exporter — Blender Plugin

Exporte modelos 3D diretamente do Blender para AR (Realidade Aumentada) e compartilhe via QR Code — sem configuração, sem GitHub Pages, tudo hospedado no seu próprio backend Cloudflare.

## Instalação (Blender 4.2+ — Extensions Platform)

1. No Blender: **Edit → Preferences → Get Extensions**
2. Pesquise por **AR USDZ Exporter**
3. Clique em **Install**

Ou instale manualmente:

1. Baixe o arquivo `ar_usdz_exporter.zip` da [página de releases](https://github.com/geancg/blender-ar/releases)
2. **Edit → Preferences → Add-ons → Install from Disk**
3. Selecione o zip

---

## Como usar

1. Selecione um objeto na cena
2. Abra o painel lateral: **N → AR Exporter**
3. Clique em **Exportar para AR**
4. Escaneie o QR Code no celular — o modelo abre direto em AR
